Áreas de Conocimiento

Explora las diferentes áreas tecnológicas que abordamos en nuestro departamento

Programación

Aprende los fundamentos de la programación con Python, Java, JavaScript y desarrollo web. Desde conceptos básicos hasta proyectos avanzados.

Python Java Web

Robótica e IA

Construcción y programación de robots, introducción a la inteligencia artificial y machine learning aplicado.

Arduino IA Sensores

Redes y Sistemas

Configuración de redes, administración de sistemas operativos y fundamentos de ciberseguridad.

Redes Linux Seguridad

Desarrollo Mobile

Creación de aplicaciones móviles para Android e iOS. Diseño de interfaces y experiencia de usuario.

Android Flutter UX/UI

Bases de Datos

Diseño, gestión y consulta de bases de datos relacionales y no relacionales. SQL y NoSQL.

SQL MongoDB MySQL

Desarrollo de Videojuegos

Diseño y programación de videojuegos 2D y 3D utilizando motores modernos como Unity y Godot.

Unity C# Godot
